## Reproduction and assumptions

From the repository root:

```sh
~/w/glacier-lean/.venv/bin/python - <<'PY'
from ventures.blocks.feeds.core import fetch_source, registry
fetch_source("fsis_recalls", registry()["fsis_recalls"])
PY
```

The adapter raises `urllib.error.HTTPError: HTTP Error 403: Forbidden`. Its request includes the official FSIS recalls-page `Referer` and `Accept: application/json`. A direct `urllib` probe with the same endpoint and headers but the short user-agent `Glacier public-data client` returned HTTP 200 and JSON. The adapter's current full user-agent string was therefore suspected, but not changed because two self-fix attempts reached the same 403 and the escalation limit requires stopping.

The failed sync correctly leaves the source in error state and raises an alert; it does not report an empty successful feed. Please compare the user-agent behavior in a fresh fixer context and verify the returned record fields before resuming this source.
