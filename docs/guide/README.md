# Glacier guide

Glacier helps you set up work that can run on your computer, using AI helpers and ordinary steps. You can start with a ready-made example, look over its steps, and run it.
Each run can be checked against rules chosen ahead of time. You can review saved notes, see who wrote them, and restore an earlier version.
Glacier keeps its files on your computer unless you choose a step that sends information elsewhere.
