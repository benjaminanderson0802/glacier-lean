# To browse memory and notes

Glacier memory is made of plain text notes saved on your computer. You can read them in an ordinary text editor. The notes may include things you asked Glacier to remember and records created by completed work.

Each note records who wrote it and when. A note created by an automation can also name the run that made it. Notes can link to other notes, so related information is easier to follow.

Open **Memory** > **Map** to see how notes and other saved information connect. Drag the map to move around it and scroll to zoom in or out. Drag a note to pin it in place; double-click it to unpin it. Click a note once to open it.

Changes are saved as history. You can review earlier versions and restore the version before a chosen change. This gives you a way to undo a note edit. It does not undo actions an automation took outside that note.

Glacier may use related notes as context for an AI step. Keep private information in mind when deciding what to save. See [Safety and secrets](04-safety-and-secrets.md).
