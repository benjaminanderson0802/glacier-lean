# Add things to memory

## What you will do

You will add a file, a note, an exported chat or a coding session, then find saved information again.

## What you need

Have something you are allowed to save: a file, text to remember, an official chat export, or a coding session on this computer. Avoid adding passwords or private information you do not want saved.

## Steps

1. Open **Memory**, then choose **Add**.
2. Choose **Files** to drop a file into the box or click it to browse. Optionally fill **Add to project (optional)**, then choose **Add to memory**.
3. Choose **Text** to enter a title and the words to keep, then choose **Add to memory**.
4. Choose **Chat import**, select **ChatGPT** or **Claude**, and add that service's exported ZIP or JSON file. Choose **Add to memory**. Later, choose **Check for new chats** to look for more exported chats already set up for import.
5. Choose **Coding sessions**, select a session, then choose **Save to memory**. Sessions are shown read-only; Glacier does not change them.
6. Choose **Notes** to browse saved items. Use **Search memory…** to find matching words, or choose **Map** to see how items connect. Select a note in the map to open it.

## If something goes wrong

Read the error shown under the form. A file may be rejected with “This file type is not allowed.” Choose a supported file type. For chat import, choose the right source and a valid export; Glacier may say “This does not look like a valid ChatGPT export” or “This does not look like a valid Claude export.” Export the data again and try the matching source. If no coding sessions are found, the list says “No Codex or OpenCode sessions found on this computer.”

## What to try next

Open a note, choose **Edit**, and save a small change. If you change your mind, see [Undo a change](05-undo.md).
