# Ask Glacier to set something up for you

## What you will do

You will describe a weekly task and review the automation Glacier suggests before you accept it.

## What you need

Think of a small, repeatable task. Say what should happen, when it should happen, and what a useful result looks like. Do not include passwords or private details.

## Steps

1. Open **Ask**.
2. In **Type a message…**, describe your weekly task in everyday language. For example: “Every Friday, remind me to review the notes I added this week.” Choose **Send**.
3. Read Glacier's reply and the suggested automation. Check that its name and steps match what you asked for.
4. Choose **Approve** to accept the suggestion, **Edit** to adjust it first, or **Reject** if you do not want it. Approval opens the automation in the builder. Review it and save it before running.

## If something goes wrong

If Glacier says it could not reach the assistant, check that Glacier is running and try again. If it says “The assistant could not answer. Please try again.”, send a shorter or clearer request. If no suggestion appears, explain the task in another way.

## What to try next

Open **Automations**, find the saved item and review it in the run view before choosing **Run**. For a ready-made starting point, see [Your first automation from a template](01-first-automation.md).
