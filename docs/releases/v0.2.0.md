# Glacier 0.2.0

The first big update. It is installed once by hand; from the next release on, Glacier offers updates in Settings > About and installs them when you click Install.

## New
- Build (was Ask): a conversation that keeps asking until it understands your whole project, then writes a spec you approve, proposes the smallest team that can build it (lead, builders, an independent evaluator, and a researcher or reviewer when needed), and runs that team in Automations until it is done. The planner that designs the team never works on it. Only the evaluator can mark a feature as passing. If work stalls it retries, resets, re-plans, and only then asks you.
- Every engine: Build runs on your subscription command-line tool by default (Codex), with a one-click switch to an API (OpenAI-compatible or Anthropic) or a local model. Subscription and API teams work in parallel; local models work one task at a time with a fresh memory per task.
- API engines only run after you turn one on with your own key and set a monthly cap; Glacier shows the spend and stops at the cap.
- Every engine knows Glacier: what it is, how its screens work, your memory, the current state of your flows, and your past chats when that option is on.
- New look: a real retro game style drawn as pixel art (sprite frames, dither backgrounds, 8x8 icons, the Press Start 2P font, a game menu with a cursor, and a key-hint bar).
- Delete with undo on flows, runs, notes, claims, chats, uploaded files and imported templates.
- Memory map with real physics: linked notes pull together, others push apart; drag, pin, zoom and pan.
- Automations canvas: snap to grid, automatic layout, minimap, fit to view, keyboard delete with undo, and template pictures drawn from the real template so you see what you get.
- Updates: Glacier checks for new versions and installs them only when you click Install.
- Flows can start when a file appears in a folder or a web request arrives. New step: call a web API.
- Spanish for every screen (Settings > General).
- Glacier can build and verify features on itself: three real features in a row passed its own independent checks.

## Fixed
- The window's minimise and close buttons work.
- No terminal window opens when Glacier starts; opening Glacier twice focuses the open window.
- Ask finds Codex and installed local models correctly, and says plainly when a model is missing.
- No unasked quotes or motivational text; the pixel character is gone.
- Every action that changes something is recorded in the audit log.
- Windows: the tool check no longer hangs or shows the "Unsupported 16-bit application" box; saving notes works with short 8.3 folder names or another drive; timed-out commands stop promptly.
- Notes written by hand no longer get an empty run_id line; the engine key never appears in logs.
- Runs finish right after their last step even on a busy computer; faster saves.
