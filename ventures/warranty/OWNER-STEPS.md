# Owner steps

## One setup session — about 15 minutes if the accounts already exist

1. Open [Jobber](https://secure.getjobber.com/). Click **Gear → Settings → Custom Fields → Jobs → Add Field** four times. For each field, set **Applies to: Jobs**, paste its name from [`JOBBER-SETUP.md`](JOBBER-SETUP.md), choose **Text**, leave **Default Value** blank, leave **Transferable Field** unchecked, and save. The exact names to paste are `Equipment Brand`, `Equipment Model`, `Equipment Serial`, and `Install Date`. Enter the corresponding actual value on each completed installation job; use `YYYY-MM-DD` for Install Date.

2. If a live read-only check is needed, open the [Jobber Developer Center](https://developer.getjobber.com/), click **Apps → New**, and create a draft test app named `Glacier Warranty Intake`. Paste this description: `Read completed HVAC installation jobs to prepare a local warranty review queue.` Use only the read scopes needed for the check; do not publish the app. From **Manage Apps**, click the app's **⋯ → Test in GraphiQL**, authorize a dedicated test Jobber account with **Allow Access**, then in GraphiQL's **Headers** copy the `Authorization: Bearer …` value. In Glacier, open **Settings → Secrets** and save the app's Client ID as `jobber_client_id`, Client Secret as `jobber_client_secret`, and that Bearer token value as `jobber_access_token`. Run the read-only check shown in [`README.md`](README.md). This temporary token expires after 60 minutes; GraphiQL test tokens do not establish a recurring production connection.

Jobber calls for custom fields on Jobs, and the GraphiQL test flow is documented in its [custom fields guide](https://help.getjobber.com/en/articles/custom-fields/) and [Developer Center getting-started guide](https://developer.getjobber.com/docs/getting_started/). Do not create a paid account or upgrade a Jobber plan without separate approval. If the account does not already include custom fields, stop here and use the local fixture mode.

No portal terms decision or manufacturer terms review is needed for this setup: the workflow reads Jobber and prepares local records only. Brand portal automation remains disabled. The current official pages do not establish permission for an outside service to prepare or automate a registration, so those items remain `uncertain — please check` and are not owner tasks unless that feature is separately proposed. No outreach is part of this venture card.
