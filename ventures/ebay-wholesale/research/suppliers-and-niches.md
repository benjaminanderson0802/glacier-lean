# eBay wholesale dropship research

Research checked 2026-10-11. **This is a screening memo, not proof of eBay demand or supplier authorization.** eBay seller research could not be obtained keylessly: Marketplace Insights is a limited-release API requiring eBay business approval; Browse returns active listings, not sold history. eBay's current User Agreement prohibits automated access/scraping without eBay's prior express permission. See [Marketplace Insights API restrictions](https://developer.ebay.com/api-docs/buy/marketplace-insights/static/overview.html), [Buy API overview](https://developer.ebay.com/api-docs/buy/static/buy-overview.html), [eBay User Agreement](https://www.ebay.com/help/policies/member-behavior-policies/user-agreement?id=4259), and [API License Agreement](https://developer.ebay.com/join/api-license-agreement). No sold data was queried, scraped, or invented. Exact permission-gated search work is in [APIFY-QUERIES.md](APIFY-QUERIES.md).

### Price and margin rule

The working price floor is: `(supplier unit cost + supplier-to-buyer shipping + other seller-paid variable costs + minimum profit + fixed eBay fee) / (1 - effective eBay percentage fees)`, rounded upward to cents. The owner rules say minimize profit and maximize accepted offers; this tool therefore defaults conceptually to a $0 contribution floor, but the operator must enter the current, category-specific total fee rate and an explicit minimum-profit value. This is a break-even floor, not a target margin. It excludes costs unless they are supplied. Never reuse a fee rate across categories or promotions without checking the current eBay fee schedule. Do not publish when the verified supplier landed price, eBay fee, buyer-shipping setup, returns exposure, or MAP rules are missing.
