# Privacy policy — Alabama Contractor Roster Check

**Contact:** `{{BUSINESS_EMAIL}}`

This Actor processes information that the customer submits to the Apify platform. The customer uploads a roster CSV they are authorized to use, provides a source URL and snapshot date, and enters license numbers or business names to compare. The Actor reads the uploaded file from Apify file storage, compares it in memory, and writes result rows to that run's Apify dataset. It does not browse the Alabama board, fetch the source URL, use a proxy, or send the roster to a third-party data provider.

The Actor's result rows may repeat the query and fields from a matching roster record. Do not submit information you are not authorized to process. The customer controls their Apify account, run inputs, datasets, and platform retention settings. Apify's own privacy and retention terms apply to data stored by the Apify platform.

The Actor does not request account credentials or API keys. It does not intentionally store roster content beyond the active run's input and output. We do not use roster contents for advertising, prospecting, or model training.

The result is a dated comparison against the supplied snapshot. A `match` is not a certification, legal qualification, insurance check, or guarantee that the roster is current. Confirm important decisions with the relevant board. Contact `{{BUSINESS_EMAIL}}` for privacy questions or run support. Remove private values before sharing a run ID or example.
