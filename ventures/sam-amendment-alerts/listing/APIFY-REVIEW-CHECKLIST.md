# Apify publishing review checklist

Official docs:

- Publish an Actor: https://docs.apify.com/actors/publishing/publish
- Store publishing terms: https://docs.apify.com/legal/store-publishing-terms-and-conditions
- Actor create/configuration fields (description, title, SEO, icon, categories): https://docs.apify.com/api/v2/actors-post
- Actor README: https://docs.apify.com/actors/publishing/actor-readme
- Input schema: https://docs.apify.com/actors/development/actor-definition/input-schema/specification/v1
- Secret input fields: https://docs.apify.com/actors/development/actor-definition/input-schema/secret-input
- Dataset schema: https://docs.apify.com/platform/storage/dataset-schema
- Pay per event: https://docs.apify.com/actors/publishing/monetize/pay-per-event
- Actor permissions: https://docs.apify.com/actors/development/permissions

The official publishing page lists a README, logo and description, monetization, sample output, output schema, and permission level. It does not make screenshots a required field. This folder contains paste-ready Store text, PNG logo asset, title/slug, short and SEO descriptions, category/search terms, JSON sample, schemas, privacy policy, pricing recommendation, and least-privilege permission guidance. The listing disclaimers avoid implying U.S. government affiliation, consistent with Apify's publishing terms. The owner reviews Console settings and submits the listing.

Expected billing review: only verified new-notice/amendment/deadline-change rows charge after they are written. First baseline, no-change, uncertain, incomplete snapshot, API outage, and quota/rate-limit errors are free. Disable automatic start and dataset-item events to avoid duplicate or non-value billing.
