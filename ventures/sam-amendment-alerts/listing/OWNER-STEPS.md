# Owner steps before Store publication

1. **Account and upload:** create/configure the Apify developer and payout account yourself, then upload this folder with `npm exec --yes --package=apify-cli@1.10.0 -- apify push` from `ventures/sam-amendment-alerts` (log in locally; never put the Apify token in a file).
2. **Review and submit:** replace `{{BUSINESS_EMAIL}}`, approve the event price and platform-usage/run cap settings, confirm automatic start/item charges are disabled, review the secret-key behavior, permissions, README and privacy policy, then submit the first public Store listing yourself.

No Apify account, payout setup, Actor upload, listing submission, publication, or payment has been performed. Customers provide their own free SAM.gov API key in the encrypted input field; the owner does not need to put a key in this repository or listing. No public source is contacted by this draft and no live credentialed API request was performed.
