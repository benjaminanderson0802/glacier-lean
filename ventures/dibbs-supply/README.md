# DIBBS government supply

This venture reads SAM.gov Contract Opportunities API v2 `opportunitiesData` response envelopes for DLA notices under NAICS 423840, 423830, 423710, 423610, and 423120. It ranks the notices for review and prepares source-linked bid sheets and quote files only from exact DIBBS solicitation details and supplier quotes you enter. SAM.gov is a discovery feed: verify every candidate on DIBBS and enter its official DIBBS detail URL and solicitation facts before a quote can be prepared. Glacier does not create accounts, contact suppliers, buy parts, sign certifications, or submit bids.

The public SAM.gov API requires a free public API key. After creating your own SAM.gov account, request the key from Account Details as described in the [official API guide](https://open.gsa.gov/api/get-opportunities-public-api/), then save it in [Glacier Settings → Secrets](#/settings/secrets) as `sam_api_key`. The venture manifest names this required secret; runtime code resolves it from Glacier Secrets rather than a fixture, flow input, or command-line argument. The daily run makes read-only, paginated API requests for each NAICS code and filters returned rows against DLA department/organization fields. It writes ranked candidates to `$GLACIER_HOME/ventures/dibbs-supply/drafts/sam-opportunities.json`. No SAM or DIBBS consent banner is acknowledged, and Glacier does not log in to either site.

Open the [DIBBS solicitation search](https://www.dibbs.bsm.dla.mil/rfq/) yourself, inspect each candidate, and enter its exact official DIBBS detail URL, number, NSN, part number, due date, quantity, eligibility, required CSV fields and output filename in `$GLACIER_HOME/ventures/dibbs-supply/incoming/solicitations.json`. Add verified `quote_sources` (manufacturer/distributor type, email or HTTPS contact URL, on-file authorization document, and a supplier quote due date) to prepare request drafts. Add returned supplier quotes and their authorization and traceability document paths to `quotes.json`. Missing or conflicting facts remain **uncertain — please check**. Closed, restricted, expired or electronic solicitations are excluded.

Run **Prepare DIBBS quote files** each day in Glacier. The command reads code from `$GLACIER_PROJECT_ROOT` when set, or the project at `$HOME/w/glacier-lean` by default; set the variable to your Glacier project directory if it is elsewhere. It refreshes the SAM.gov candidate list, checks exact owner-entered DIBBS solicitation and supplier quote matches, ranks supported bids by gross margin, then prepares quote-request drafts for manufacturer/distributor contacts you supplied and a separate CSV using each solicitation's required field order. The margin is `(unit bid price - unit cost) / unit bid price`; it does not include costs not present in the supplier quote. Quote files are drafts for your review. Traceability records must be on file before shipping. If the API key is missing or SAM.gov is unavailable, the run reports an alert; manually entered exact DIBBS records can still be checked, but the source refresh is not reported as successful.

The result vocabulary is **match**, **no match found in DLA DIBBS and supplier quotes as of [date]**, or **uncertain — please check**. A `match` means the supplied facts passed the script's checks; it is not a legal conclusion, award prediction, or government submission. The SAM.gov candidate file reports its page count, cap, and source alerts; a capped result is explicitly incomplete.

## Your steps

1. Complete [SAM.gov](https://sam.gov/entity-registration) and [CAGE](https://cage.dla.mil/) registration yourself. Request a free public API key using the [SAM.gov API guide](https://open.gsa.gov/api/get-opportunities-public-api/) and add it as `sam_api_key` in [Glacier Secrets](#/settings/secrets).
2. Review solicitations, request quotes only from original manufacturers or verified authorized distributors, provide quote evidence, and approve each exact parts commitment in the separate Glacier approval step before purchase.
3. Review each prepared bid, then personally sign and submit it in DIBBS. Keep traceability documents before shipping.

## Local input files

- `incoming/solicitations.json`: JSON array of verified solicitation details, including the exact official DIBBS detail URL with its solicitation number. Every `required_fields` entry must be supported by a script mapping (`solicitation_number`, `nsn`, `part_number`, `quantity`, `unit_price`, or `supplier_name`). `quote_file` must be a plain `.csv` filename.
- `incoming/quotes.json`: JSON array with solicitation/part number, supplier name and type (`manufacturer` or `authorized_distributor`), authorization and traceability evidence paths, quoted quantity, unit cost, and unit bid price.
- Quote requests are saved under `drafts/quote-request-drafts.json` with an exact recipient, subject, and prefilled message. Review the drafts at the approval step and send them manually; Glacier never contacts suppliers. Bid drafts are written under `drafts/`; no outbound action is performed. Keep customer or supplier documents local and delete them 30 days after the job closes unless retention is requested.

DIBBS, SAM.gov and CAGE accounts are owner steps. Glacier never enters credentials or submits anything to a government agency. No paid service is used.
