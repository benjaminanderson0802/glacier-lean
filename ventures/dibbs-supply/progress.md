# Progress — DIBBS government supply

PH12.19 remains in progress. The scheduled daily flow now reads DLA opportunity candidates from SAM.gov Contract Opportunities API v2, filtered to NAICS 423840, 423830, 423710, 423610, and 423120. The API key is owner-supplied through Glacier Secrets as `sam_api_key`. SAM.gov rows are discovery-only; each solicitation's exact DIBBS detail URL and bid facts still require owner verification and entry. Supplier quotes remain owner-entered, and Glacier never contacts suppliers, purchases parts, signs, or submits bids.

The public `parse_sam_opportunities` adapter consumes the synthetic SAM.gov v2 `opportunitiesData` envelope, filters DLA rows by the caller's NAICS allowlist, and preserves official SAM.gov links and ranking fields. `venture.json` now names `sam_api_key` as a required Glacier secret, resolved at runtime through Glacier Secrets; no key is in the fixture or repository. The independent acceptance checks verify these behaviors. Fixture parsing is not a live API-key canary: no API key was configured and no live SAM.gov request or live solicitation result is claimed. DIBBS's public page still returns the DoD consent banner; Glacier does not interact with it.
