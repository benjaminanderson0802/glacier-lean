# OSHA customer intake

Save customer-confirmed records as `intake.json` in the Glacier OSHA venture data folder. Include establishment identity/address/industry code/employee count, year, the OSHA injury-log totals, hours worked, average headcount, executive name/title, and explicit `coverage_confirmed` and `customer_confirmed` values. Use the example intake structure in the venture README. Never include OSHA account credentials here.
