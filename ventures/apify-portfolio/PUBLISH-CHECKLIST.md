One owner sitting for all six Actors. The existing account entries below must be **updated in place**, not duplicated. This commit must first be integrated into the public `glacier-final` branch; the Git URLs are prefilled for that branch.

## 1. Verify the account once

Open [Apify account settings](https://console.apify.com/account/integrations) and complete the developer/business and payout verification Apify requests. Return to the [Actors console](https://console.apify.com/actors). This account step covers all six listings; do not repeat it per Actor.

## 2. Update, build, price, and publish each Actor

For each row, open the linked existing Actor. In **Source**, choose **Git repository** → **Change** provider → **GitHub** and authorize Apify if prompted. Select repository `benjaminanderson0802/glacier-lean`, then paste the exact Git URL from the table as the source URL (it selects both the branch and Actor subfolder). Save the source. Open **Build** and start a build from the connected source. After a successful build, open the Store/publishing settings, set the title and description from the table, choose **Pay per event**, add exactly the named event at the listed price, include platform usage, and set the maximum run charge shown. Remove/disable any automatic Actor-start or default-dataset-item event. Review the sample input and output in the Actor README, then publish the listing yourself.

Apify's current documented Git flow is **Actor → Source → Git repository → Change provider → GitHub → repository and Git URL**. The branch/folder URL syntax is `repository#branch:directory`; see [Apify source types](https://docs.apify.com/actors/development/deployment/source-types) and [GitHub integration](https://docs.apify.com/integrations/github). Console labels may move; use the Source and Store/publishing sections on each Actor page.
