Search totals include irrelevant results; SAM's first 100 of 131 results are a sample. A reproducible rough relevance filter matches title+slug against `census.*permit`, `fdic|bankfind`, `sam[ .-]?gov`, `osha`, `npi|nppes`, or `epa|echo`. It still includes adjacent products (especially EPA and broad screening tools). Counts are listing observations, not unique buyers; creators' own canaries can account for regular runs. ## Why each adds value and suggested prices

- **Census:** normalized state FIPS, separate estimates/reported counts, correct dollars (source values are thousands), explicit month comparisons, both source hashes, and missing-value uncertainty. Proposed `state-comparison` **$0.002 per successfully compared state** (51 states/DC = $0.102); no start fee. [aether_studio/census-state-building-permit-change-monitor](https://apify.com/aether_studio/census-state-building-permit-change-monitor): 49 lifetime runs, 1 monthly user, 27 public runs/30d; $0.001/result plus $0.005 start. Our sample 3 states costs $0.006 versus $0.008 at those listed competitor rates. Not cheaper for all-state runs. Period deltas are not revision detection; fingerprints allow a downstream consumer to detect changed vintages.
- **FDIC:** exact certificate or state lookup, conservative whole-snapshot failure, bounded pagination, source vintage, dates and truncation flags. Proposed `bank-record` **$0.002 per returned institution**; no start fee. [pink_comic/fdic-bankfind-search](https://apify.com/pink_comic/fdic-bankfind-search): 397 lifetime runs, 1 monthly user, 27 public runs/30d; $0.002/result + $0.0001 start. [copious_atoll/fdic-bank-data](https://apify.com/copious_atoll/fdic-bank-data): 186 runs, 0 monthly users, $0.001/result + $0.00005 start. We charge for convenient stable output, not exclusive data or financial advice.
- **NPI:** exact user-supplied IDs, checksum validation before requests, deduplication, practice address selection, primary taxonomy and dated provenance. Proposed `provider-record` **$0.003 per returned provider** (50 = $0.15); no-match/error free, no start fee. [agenscrape/nppes-npi-registry-api](https://apify.com/agenscrape/nppes-npi-registry-api): 1,864 lifetime runs, 1 monthly user, 161 public runs/30d, $0.0005/result + $0.0005 start. [accountable_eel/npi-provider-lookup](https://apify.com/accountable_eel/npi-provider-lookup): 87 runs, 1 monthly user, $0.004/lookup at FREE tier + $0.00005 start. Proposed pricing sits between low-cost bulk retrieval and exact-lookup competitors; buyer willingness to pay remains unproven.

Prices are suggestions for owner configuration, not automatic platform settings. Only custom successful-record events should be configured: **no synthetic Actor-start or default-dataset-item charges**, which would undermine free outage results. Platform compute can still cost the developer; small runs may be unprofitable. Measure actual cloud costs after an owner-controlled build; no cloud compute was purchased for this task. See [Apify monetization](https://docs.apify.com/actors/publishing/monetize).

## Source access and reuse basis

Only these official read-only interfaces are used. No UI scraping, login, proxy rotation or CAPTCHA bypass. APIs are keyless as tested; each Actor makes serial requests at most once per second, bounded response sizes, timeouts, and one bounded retry for 429/503. Other redirects/errors become uncertain; there is no fallback to unofficial scraping.

- **Census:** the [BPS landing page](https://www.census.gov/construction/bps/index.html) explicitly links downloadable [ASCII files](https://www2.census.gov/econ/bps/State/). The [state format specification](https://www2.census.gov/econ/bps/Documentation/stateasc.pdf) defines the 29 columns, imputed/reported distinction and thousands-of-dollars unit. Census's [public-access policy](https://www2.census.gov/foia/ds_policies/ds027.pdf) identifies employee-created data/works as generally outside US copyright protection; [citation guidance](https://www.census.gov/about/policies/citation.html) supports attribution. We expose source URLs/times and transform published aggregate data only. Monthly changes are not property-level permit leads or forecasts.
- **FDIC:** [BankFind API docs](https://api.fdic.gov/banks/docs) explicitly invite applications using public bank data and say API keys are currently not required. [Bulk/API access](https://banks.data.fdic.gov/bankfind-suite/bulkData) explicitly permits filtered downloads. Output preserves source identifiers and dates; no FDIC branding/endorsement, insured-balance guarantee or financial recommendation. We use the published developer interface for factual institution fields, not bank-site content.
- **CMS:** [CMS's provider-information guidance](https://www.cms.gov/initiatives/burden-reduction/overview/interoperability/frequently-asked-questions/bulk-upload-reviewing-updating-digital-contact-information-national-plan-provider-enumeration-system) identifies the public NPPES API; the [dissemination notice](https://www.cms.gov/regulations-and-guidance/administrative-simplification/nationalprovidentstand/downloads/datadisseminationnpi.pdf) establishes public query/download access. [CMS data principles](https://www.cms.gov/data-research/cms-data/cms-data-principles-and-operating-norms) describe publicly posted data as freely available and machine readable. This is public registry data, not patient records; enumeration is not credentialing. The Actor excludes contact phone/fax, authorized officials and other identifiers, and makes no enrichment/outreach requests. Source fields may be stale and practice addresses may identify individuals.

Source-access review supports these specific public API/bulk paths, not blanket clearance for every government website. No agency affiliation is implied. The official source remains free; our fee is for normalization and the Actor workflow.
