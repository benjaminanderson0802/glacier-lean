# Sample deliverable provenance

`job-9001.md` and `job-9001.pdf` were generated on **2026-10-10** by the local prototype from [`tests/fixtures/jobber_completed_job.json`](../tests/fixtures/jobber_completed_job.json). The fixture is synthetic and mirrors the Jobber GraphQL response fields selected by the read-only connector; it is not a real customer's job.

The official Jobber API is not keyless for customer jobs. No public real-job source could be used without account authorization, so this sample deliberately uses the fixture instead of claiming to contain real public data. API shape/source references in the connector's fixture record: [Jobber API queries and mutations](https://developer.getjobber.com/docs/using_jobbers_api/api_queries_and_mutations/), [Jobber API getting started](https://developer.getjobber.com/docs/getting_started/), [custom fields](https://developer.getjobber.com/docs/using_jobbers_api/custom_fields/), [API versioning](https://developer.getjobber.com/docs/using_jobbers_api/api_versioning/).

The customer and equipment details are fictional; treat these files only as a format demonstration.
